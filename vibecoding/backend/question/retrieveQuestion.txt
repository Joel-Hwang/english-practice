Write Backend Code about submitting quizez by using MVC pattern

a) Model
File: model/question.py
Model Name: Question
Model attributes
- group: str
- questions: str[]
- createdAt: datetime (default: datetime.now(timezone.utc))


b) Repository
1. File: repository/questionRepository.py
2. Method: retrieveQuestion(group: str)
2-1. Description
- find the latest question document in db["question"]. It should be filtered by "group"

c) Service
1. Service: service/questionService.py
2. Method: retrieveQuestion(group: str)
3. Description: 
- call the repository
4. return: Question document. if no exists, return an empty array
5. Test Cases (test/test_questionService.py)
- Successful retrieving questions.

d) Controller
1. Controller: controller/questionController.py
2. Method: retrieveQuestion()
3. EndPoint: /login, POST
4. Description: 
- call service method with the group information in user. user is in the session.
- Do not try except. We have global Exception Handler.
5. response: if the serivce doesn't throw any exceptions, the controller will return the service's result.
