Write Backend Code about change password by using MVC pattern

a) Model
Model: model/user.py

Model Name: ChangePassword
Model attributes
- id: str
- newPassword: str
- oldPassword: str

b) Repository
1. Repository: repository/userRepository.py
2. Method: updatePassword(user: User)
2-1. Description:
- update User password to db["user"] 
     
c) Service
1. Service: service/userService.py
2. Method: changePassword(param: ChangePassword)
3. Description: 
- find a user. if there is no user,  throw the HTTPException with proper detail message (status_code=422, detail=message);
- If it doesn't match the oldPassword, it will throw a HTTPException with a proper message (status_code=400, detail=message)
- update the newPassword by calling userRepository. 
- Encrype the newPassword with bcrypt.hashpw
4. return: void
5. Test Cases (test/test_userService.py)
- Successful changing password.

d) Controller
1. Controller: controller/userController.py
2. Method: changePassword
3. EndPoint: /user/changepassword, POST
4. Description: 
- Do not try except. We have global Exception Handler.
- call service method with the user information.
6. response: if the serivce doesn't throw any exceptions, the controller will respond with proper message {message: message}
